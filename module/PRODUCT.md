## Platform

web (Red Bull EMP extension module, mounted inside the page's Extension Modules rail)

## Users

Red Bull consumer on a staged EMP page; secondary: the DPS agent iterating on this module during an engagement build.

## Brand Personality

energetic, precise, competitive — a pit-lane arcade micro-game. Playful but disciplined; never cartoonish.

## Purpose

A drop-to-stack canvas game ("Stack — a Red Bull drop") that demonstrates a self-contained engagement module: React + Canvas, no game deps, Cosmos buttons for pointer users, keyboard for everyone. This module is the *output* of an engagement build; it must stay self-contained and mountable by the EMP host.
